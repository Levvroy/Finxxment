# Sheet Formulas & Formatting — Design Notes

This documents the visual design of the Google Sheet (`apps-script/01-sheet-formatting.gs`,
`02-panduan-sheet.gs`) and a set of real formula bugs found and fixed while building it. If
you're extending the sheet schema later, read the "formula correctness rules" section before
adding a new computed column.

## Visual design

- **Panduan tab** (`📖 Panduan`, first tab) — an in-spreadsheet guide covering every sheet's
  purpose, every Telegram command, the category/sumber-dana legend, and a status/color legend,
  so someone can understand the whole system by opening the Sheet without reading this repo.
  Rebuilt by `provisionPanduanSheet_()`, safe to re-run.
- **Consistent header style** across every sheet: dark navy header row, white bold text, frozen.
- **Color-coded conditional formatting** so state is readable at a glance instead of requiring
  you to read the raw text: `Jenis` (green Masuk / red Keluar), `Status Verifikasi` (green
  Verified, gray Unverified, amber Mismatch-Resolved, red Perlu Review Manual), `Pending
  Transaksi.Status` (amber Waiting, green Resolved, gray Expired), `Hutang Piutang.Arah` and
  `.Status` (including a whole-row red highlight for entries overdue *and* still unpaid),
  `Tabungan Goals.Status`.
- **Row banding** (alternating shading) on every data sheet for scan-ability.
- **Rupiah currency format** (`"Rp"#,##0;-"Rp"#,##0`) on every money column instead of raw
  numbers; date/datetime formats on every date column; a `0"%"` custom format on percentage
  columns (native "Percent" format would incorrectly multiply our already-0-100-range values by
  100 again).
- **A text progress bar** (`Tabungan Goals.Progress Bar`, e.g. `██████░░░░`) generated by
  `REPT()`, capped so it never shows more than 10 blocks or a negative count even if a goal is
  over-saved.
- **Hidden implementation-detail columns** (`Pending Transaksi.Raw Payload`, the Dashboard's
  chart QUERY helper columns from column O onward) so the sheet a human looks at stays free of
  serialized JSON and raw formulas that aren't meant to be read directly.
- **Dashboard title banner** + a fixed row layout (`apps-script/05-dashboard-layout.gs`) keeping
  every section (Saldo, Burn Rate, Budget vs Actual, Hutang Piutang, Tabungan Goals) in its own
  colored block, with the chart-helper formulas confined to a completely separate column band
  so the two areas can never spill into each other (see bug below).
- **Tab colors** per sheet for quick visual identification when many tabs are open.

Re-run `provisionFinxxmentSheets()` (or just the "Re-apply Formatting" / "Recalculate ..." menu
items under **Finxxment**) any time you want the look reapplied.

## Formula bugs found and fixed

**1. Dashboard layout collision (`#REF!` risk).** The chart QUERY helper formulas and the text
summary blocks used to share the same columns (1, 4, 7, 10, 13). With enough budget categories
or goals, the QUERY formulas' multi-row spill would have collided with the text blocks and
thrown "Array result was not expanded because it would overwrite data in ...". Fixed by moving
every chart helper into its own column band starting at column O (`DASHBOARD_CHART_HELPER_COL`
in `05-dashboard-layout.gs`), completely separate from the columns A-E the text blocks use.

**2. `Tabungan Goals` append-safety.** `Nominal Terkumpul` and `Progress %` are `ARRAYFORMULA`s
that spill down their column automatically. They used to sit *between* `Sumber Dana` and
`Status` in the header order - columns n8n's `/goal tambah` append does and doesn't write to,
respectively. Because Sheets' append has to send a contiguous value range, writing to `Status`
while skipping the two formula columns risked also writing blank values into the formula cells,
permanently truncating the `ARRAYFORMULA`. Fixed by reordering `GOALS_HEADERS` so both computed
columns (`Nominal Terkumpul`, `Progress %`, and the new `Progress Bar`) are the trailing columns
- after everything n8n ever writes - so an append can never reach them.

**3. Cashflow chart included a spurious "(empty)" bar.** The `Tag Bulan` column is an
`ARRAYFORMULA` that returns a literal empty string `""` for every one of the ~2000
pre-provisioned but still-unused rows. `QUERY(...)`'s `where P is not null` treats a
formula-produced `""` as a real (non-null) value, so it doesn't filter those rows out - the
cashflow chart ended up with an extra "(empty)" group summing all the blank rows. Fixed by
filtering `where P != ''` instead.

**4. "This month" / "last month" reports could include the wrong year.** Several places checked
`month(x) === thisMonth` without also checking the year - meaning that once more than ~12
months of transaction history exist, "bulan ini" or "bulan lalu" would also match this same
calendar month from *every* earlier year. Fixed in:
   - `apps-script/10-dashboard-charts.gs` — the kategori pie, sumber-dana pie, and top-5
     QUERY formulas (added `and year(C) = year(today())`).
   - `apps-script/40-webhook-api.gs` — `buildLaporanPayload_`'s `bulan_lalu` branch (now
     computes the actual previous-month `Date` via `new Date(year, month-1, 1)`, which also
     correctly rolls the year back in January).
   - `n8n/workflows/01-main-input-handler.json` — the `/laporan` command's `Code: Aggregate
     Laporan` node, same `bulan_lalu` fix.
   - `n8n/workflows/03-scheduled-report.json` — `Code: Aggregate + Insight Data` was missing
     the year check entirely for *both* "this month" and "last month"; fixed the same way.

## Formula correctness rules for future additions

- **Any `ARRAYFORMULA` column that an external writer (n8n) might append rows into must be the
  last column(s) in that sheet's header order.** If you add a new computed column, append it at
  the end, never in the middle.
- **When filtering by "this month" or "a specific past month," always check the year too.**
  `month(x) = month(today())` alone is wrong past the first year of data.
- **When a helper column is itself produced by a formula that can return `""`,** don't filter
  it with `is not null` in a `QUERY` - use `!= ''`.
- **Keep the chart-helper column band and the text-summary column band disjoint.** If you add a
  new Dashboard block, give it its own row range in `05-dashboard-layout.gs`; if you add a new
  chart, keep its helper formula in the existing `DASHBOARD_CHART_HELPER_COL` band, not in
  columns A-E.
